## About

Saya merupakan mahasiswa **Rekayasa Perangkat Lunak (RPL) di Universitas Pendidikan Indonesia** dengan fokus pada pengembangan perangkat lunak, khususnya **web development**.

Di luar perkuliahan, saya juga mulai mempelajari dasar-dasar **data engineering** dan **data analysis** sebagai bagian dari pengembangan kompetensi di bidang teknologi.

Saya percaya bahwa kode yang baik tidak harus kompleks, tetapi harus **jelas, terstruktur, dan mudah dipahami**.

-  Mengembangkan **ToDoo** dan **Cleanwash**
